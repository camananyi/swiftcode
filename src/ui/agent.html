SwiftCode is a documentation and protocol-timing support tool with humans in the loop. It never interprets ECG rhythms (rhythm words are recorded verbatim as spoken) and never directs therapy. Real-time transcription and extraction run on the local or edge SwiftInference node; Claude writes the post-event record and debrief only after ROSC or termination. It supports data locality requirements relevant to healthcare.
